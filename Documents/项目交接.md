## 1. 项目是什么

STM32H743VIT6 自制飞控。当前阶段：**传感器 + 姿态 + 健康 + 校准 + 上位机**；还没有飞行控制、电机输出、PID、失效保护。

- MCU：STM32H743VIT6，480MHz，2MB Flash
- IMU：ICM42605（SPI1，CS PC15；SPI4 第二片只初始化，未读取）
- MAG：QMC5883P（I2C1，0x2C）；IST8310 驱动保留但未启用
- BAR：DPS310（I2C2，0x76）
- USB CDC 虚拟串口，`printf` 已重定向
- 无 RTOS，协作式调度器（DWT 微秒计时）
- 上位机：PyQt5 + pyqtgraph

## 3. 当前功能

- 任务：IMU 1kHz、MAG 100Hz、BAR 50Hz、AHRS 1kHz、CAL 1kHz、PROTOCOL 10ms、LED 1s。
- AHRS：Mahony，加速度 + 磁力计修正。
- 健康：连续相同值计数；`Health_Status` 返回 true = 健康。
- 遥测：`USER_DEBUG_HOST_TOOL` 已打开，12 字段 CSV：
  `yaw,roll,pitch,magx,magy,magz,pressure,temp,gyr_health,acc_health,mag_health,bar_health`
- 校准结果在 `Task.c` 的 `AHRS_Control` 里应用，然后送 `AHRS_Update`。
- 校准参数：成功后写 bank2 最后一个扇区（单槽 + CRC32），上电由 `Flash_Load()` 加载。
- 上位机校准页：六面卡片（`FaceIcon` 矢量绘制），完成后灰色→浅蓝；WAIT 时 IMU 的 Start 按钮变成 NEXT（没有独立 NEXT）；STOP；BAR 列隐藏。

## 4. 通信协议

命令：

```
cal,imu,start
cal,imu,next
cal,imu,abort
cal,mag,start
cal,mag,abort
```

回包：

```
CAL,IMU,CHECK
CAL,IMU,COLLECT,FACE1 ... FACE6
CAL,IMU,WAIT,FACE2 ... WAIT,GYRO
CAL,IMU,COLLECT,GYRO
CAL,IMU,DONE
CAL,IMU,SAVE,ERROR
CAL,IMU,ERROR
CAL,IMU,IDLE,ABORTED
CAL,IMU,BUSY

CAL,MAG,COLLECT
CAL,MAG,DONE
CAL,MAG,SAVE,ERROR
CAL,MAG,ERROR
CAL,MAG,IDLE,ABORTED
CAL,MAG,BUSY
```

注意：

- 固件 `Cal_Start` 同时处理 `START` 和 `NEXT`；IMU 在 `WAIT` 时表示“继续”，否则表示“开始”。
- MAG 不进入 `WAIT`，启动后自动采 1000 点。
- `ERROR` = 校准失败，不再区分错误码。
- `SAVE,ERROR` = 校准成功，但 Flash 保存失败，校准标志会被清除，需要重新校准。

## 5. IMU 六面朝向（重要）

NED 坐标：X 箭头/机头，Y 右，Z 下。
`Hardware` 里 `Ax=-rawX, Ay=-rawY, Az=+rawZ`：ICM42605 原始 X/Y 与板子 NED 反向，取反后得到 NED。

实际安装：箭头面（背面）朝上，箭头指机头；上位机姿态“飞机正放”= 板子箭头面朝上。

| 面 | 物理朝向 | 加速度读数（AHRS 比力向上约定） |
|---|---|---|
| FACE1 | +Z 朝下（箭头面/背面朝上，平放） | -Z |
| FACE2 | -Z 朝下（元件面/正面朝上，倒扣） | +Z |
| FACE3 | +X 朝下（箭头/机头侧朝下） | -X |
| FACE4 | -X 朝下（机尾侧朝下） | +X |
| FACE5 | +Y 朝下（右侧朝下） | -Y |
| FACE6 | -Y 朝下（左侧朝下） | +Y |

`AHRS.c` 期望水平时 `Acc=(0,0,-g)`（比力向上），所以校准的 Plus 取加速度为 `+g` 的面：
`Plus={3,5,1}`（FACE4/6/2）、`Minus={2,4,0}`（FACE3/5/1）。
如果实际翻面与上表不同，IMU 校准后姿态会翻/漂，需要交换映射。

## 6. 校准流程

### IMU

1. 先把 FACE1（箭头面朝上）放好，点 Start。
2. `CHECK`：静止 500ms。
3. 自动采 FACE1：稳定 500ms + 500 点。
4. 进入 `WAIT FACE2`；翻面后点 NEXT。
5. 重复到 FACE6；进入 `WAIT GYRO`，放稳后点 NEXT。
6. 采 3000 点陀螺；计算 `Acc_Bias`、`Acc_Scal`、`Gyr_Bias`；回 `CAL,IMU,DONE`。

### MAG

- 1000 点 @100Hz（约 10 秒），记录三轴 min/max；
- 每轴范围 > 100 LSB，否则 `ERROR`；
- 零偏 = `(min + max) / 2`，只做硬铁。

### BAR

不做校准，只读压力和温度；上位机 BAR 校准列已隐藏。

### Flash 参数

- 链接脚本 `FLASH` 改为 1920K，最后 128KB 留给参数；
- 单槽：`0x081E0000`，bank2 sector7；
- 每条记录 64 字节，CRC32 保护前 56 字节；
- `Flash_Load()` 在 `main()` 里 `Hardware_Init()` 后调用；
- IMU/MAG `DONE` 后调用 `Flash_Save()`；写入回读失败会清校准标志并回 `SAVE,ERROR`；
- 单槽没有旧备份，擦写期间掉电会丢失校准，上电按未校准处理；
- CubeMX 不需要配 Flash 扇区；用 CubeProgrammer 确认 `SWAP_BANK` 关闭、bank2 sector7 没有写保护。
- 保存时会擦 bank2，所以代码应保持在 bank1（前 1MB）；当前程序约 56KB，远低于这个限制。

## 7. 已知问题 / 待办

按优先级：

1. **Flash 持久化已实现，待实测**：`Flash` 单槽 + CRC32；链接脚本已改 1920K；上电 Load、校准 DONE 后 Save。
2. IMU 校准没有逐面静止校验；翻面时没放稳会污染数据，后续可加。
3. `Acc_Scal` 为负时已回 `ERROR`；反复出现就按第 12 条排查。
4. `CAL ... ABORT` 不区分传感器：请求哪个传感器都会中止当前校准；上位机按钮分开，通常没问题。
5. `NEXT` 在 IDLE 误发会被当成 START；上位机只在 WAIT 显示 NEXT。
6. `State` / `Mode` / `Next` 是非 static 全局，未在头文件声明；只在本文件用，后续可加 `static`。
7. HostTool 的 BAR 控件在 `main.py` 里隐藏，`.ui` 里还在；要彻底删可从 `.ui` 删除。
8. 气压计不做校准；Dashboard 仍显示 BAR 健康。
9. 六面卡片由 `main.py` 的 `FaceIcon` 用 QPainter 绘制，不是图片文件；卡片是代码插入 `.ui` 的，改 Designer 时要同步。
10. 没有飞行控制/电机输出/PID/失效保护。
11. 第二片 ICM42605 只初始化未读取；IST8310 驱动保留但未启用。
12. IMU 校准若回 `ERROR`，表示某轴 `Acc_Scal` 为负：先确认 FACE1~6 是否按新卡片放对，再检查 `Hardware` 和 `Plus/Minus` 是否一致。
