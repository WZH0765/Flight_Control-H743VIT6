# 代码风格约定

> 适用：Flight_Control 固件（`User/`）与上位机（`HostTool/`）
> 最近更新：2026-10-24

## 1. 核心原则

1. **固定流程优先，最简逻辑。**
   这个项目大部分操作是固定步骤（上电初始化、六面校准），不为极低概率情况写大量防御分支。
   必要的流程检查保留（例如 MAG 采样范围），但不是每个函数都加错误处理。

2. **所有定义必须有消费者。**
   宏、字段、函数、全局变量，写之前先想清楚谁用；没人用就不写。
   不写“以后可能用”的代码；需要时再加，加的时候带消费者一起加。

3. **默认普通局部变量。**
   只有值需要跨函数调用保留、或中断/主循环共享时，才用 `static` / 全局。
   - 只在本函数使用、且要跨调用保留：函数内 `static`；
   - 只在同一文件多个函数共享：文件级 `static`；
   - 真正的跨文件接口：非 static 全局，并在头文件 `extern`。

4. **少写函数。**
   简单逻辑直接写在调用它的函数里；只有独立功能才单独开函数。
   不要为十几行逻辑拆 helper。

5. **格式对称、工整。**
   同一段代码的声明、赋值、`case` 尽量对齐；读起来像一张表。

## 2. 命名

- 函数：`模块_动作`
  例：`Hardware_IMURead`、`Protocol_Receive`、`Cal_Start`、`Cal_Run`。
  避免 `..._Task` 这种名词结尾。
- 类型：小写 + `_t`
  例：`sample_t`、`imu_t`、`mag_t`、`state_t`、`sensor_t`。
- 枚举值：全大写
  例：`IDLE`、`WAIT`、`COLLECT`、`IMU`、`MAG`。
- 结构体字段：PascalCase
  例：`Acc`、`Gyr`、`Mag`、`Count`、`Valid`。
- 宏：全大写，单词间下划线。
- 局部变量：PascalCase；循环变量用 `i`、`j`。

## 3. 格式

- 4 空格缩进；大括号换行（Allman）。
- `if(...)`、`for(...)` 括号前不留空格；参数逗号后不留空格。
- 声明按类型对齐：

```c
static uint8_t  Face = 0;
static uint16_t Samples = 0;
static uint32_t PhaseStart = 0;
```

- 连续赋值对齐：

```c
State      = CHECK;
Face       = 0;
Samples    = 0;
PhaseStart = Now;
```

- 每个 `case` 之间空一行；`case` 内缩进一级。
- 注释简短、中文；公共函数用块注释，简单内部逻辑不必逐行注释。
- 宏按名字长度从短到长排列，值对齐。
- 固定值直接写死；只有可能调整的参数才留宏。

## 4. 宏

- **保留**：可能调整的采样数、阈值、时间。
  当前 `Calib.h` 保留：
  `STILL_MS`、`SETTLE_MS`、`ERROR_GYR`、`MAG_SAMPLES`、`FACE_SAMPLES`、
  `GYRO_SAMPLES`、`MAG_MIN_RANGE`、`ERROR_ACC_MIN`、`ERROR_ACC_MAX`。
- **写死**：固定物理量、派生值、不会改的值。
  已写死：六面 `6`、MAG 分频 `10`、IMU 进度上报间隔 `100`。
- 新增宏时先问：它会不会被调整？不会就不要宏。

## 5. 模块与文件

- 一个模块一个目录；头文件 `#pragma once`。
- 头文件放：宏、枚举、结构体、`extern`、函数声明；`.c` 放实现和模块状态。
- CMake 使用 `file(GLOB ... CONFIGURE_DEPENDS)`；新增/删除 `.c` 会自动 reconfigure。
- 驱动层只负责读写芯片；坐标变换、单位换算、校准应用放在 `Hardware` / `Task`。

## 6. 协议约定

- ASCII 行，`\r\n` 结尾；大小写不敏感；空格或逗号分隔。
- 命令：`CAL <IMU|MAG> <START|NEXT|ABORT>`
- 回包：`CAL,<sensor>,<state>[,<detail>]`
- 状态：`CHECK` / `COLLECT` / `WAIT` / `DONE` / `ERROR` / `IDLE` / `BUSY`
- 上位机发小写即可，固件统一转大写。
- 遥测：12 字段 CSV，顺序见 `Core/Src/main.c`。

## 7. 校准约定

- **IMU**：六面 + 陀螺；FACE1~FACE6 物理朝向固定；每面采完进入 `WAIT`，上位机点 NEXT 再继续。
- **MAG**：min/max 硬铁；1000 点 @100Hz；范围不足回 `ERROR,6`。
- **BAR**：不做校准，只读压力/温度。
- 校准结果目前只在 RAM，断电丢失；Flash 持久化待做。

## 8. 提交前检查

- 每个宏、字段、函数都有消费者？
- 有没有可以变成普通局部变量的 `static`？
- 有没有可以内联的小函数？
- 有没有为极低概率情况加的多余分支？
- 格式是否对齐、对称？
- 完整构建是否通过（在 IDE 中构建）？
